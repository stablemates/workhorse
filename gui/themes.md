# Theme reference

Read the theme used by the current task. Each file contains its foundations, light/dark CSS variables, and component assignments. The bundled GraphicalProvider already resolves the captured theme in components/graphical/theme.ts and defines its variables. Use these references to verify integration and apply the named values throughout the app. Preserve the source’s internal style identities; use document.name for visible labels. Intentional local customizations take precedence afterward.
