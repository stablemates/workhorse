title: What is Workhorse for?
description: Start here to understand the PostgreSQL-backed queue, its guarantees, and the problems it solves.
---

Workhorse runs durable background jobs from PostgreSQL. It gives an application one database for
business writes, queued work, execution state, and operator evidence.

## Why keep the queue in PostgreSQL?

An application often needs a database change and some later work to agree. If those operations use
different systems, one can commit while the other fails.

`Queue.enqueue` can use the same transaction as your application write. If the transaction rolls
back, PostgreSQL removes both the business change and the job.

Workhorse needs no broker, Redis service, or PostgreSQL extension. Your application owns the
database connection, while versioned SQL functions own every lifecycle transition.

## What runs a job?

Your application registers a handler with `Worker.handle`. A `Worker` claims ready jobs, runs their
handlers, and records the result.

PostgreSQL grants each claim a temporary lease and a fence token. If a worker disappears, another
worker can recover the job, while the old worker loses permission to change it.

Handlers run outside database transactions, so delivery is at least once. External effects need a
stable provider key or another idempotency boundary.

## What evidence remains?

Workhorse stores immutable outcomes and append-only history after execution. `Queue.getJob`,
`Queue.getJobTimeline`, and the dashboard read that evidence without enlarging dispatch indexes.

Named checkpoints preserve completed stages across retries. Durable waits release the worker slot
and restart the handler later from its entry point.

## Which package do I need?

- `@workhorse/core` provides `Queue`, `Worker`, schema tools, process orchestration, and the CLI.
- `@workhorse/drizzle` adapts Drizzle databases and transactions to the core `Queryable` protocol.
- `@workhorse/hono` joins Workhorse lifecycle management to a Hono server.
- `@workhorse/dashboard` provides the operator interface and its framework-neutral server host.
