Everything below is exported from `@workhorse/core` unless noted. All packages are ESM with bundled
type declarations.

## Schema

| Export                     | Signature                                          |
| -------------------------- | -------------------------------------------------- |
| `installSchema`            | `(database: Queryable) => Promise<void>`           |
| `readSchemaVersion`        | `(database: Queryable) => Promise<number \| null>` |
| `assertSchemaCompatible`   | `(database: Queryable) => Promise<void>`           |
| `WORKHORSE_SCHEMA_VERSION` | `number` (currently `16`)                          |

## `Queue`

```ts

```

### Maintenance entry points

`tick`, `prepareHistoryPartitions`, `retainHistory`, and `pruneTerminalStorage` each return
`MaintenancePhaseResult[]` with `(phase, rowsAffected, durationMs, skippedLock, error)`.

## Adapters and worker processes

| Export                   | Purpose                                                 |
| ------------------------ | ------------------------------------------------------- |
| `createWorkhorseAdapter` | Build a provider-neutral `WorkhorseAdapter`             |
| `defineWorkerProcess`    | Type-check a dedicated worker process definition        |
| `startWorkerProcess`     | Start workers without installing global signal handlers |

## Errors

| Error                             | Raised when                                                    |
| --------------------------------- | -------------------------------------------------------------- |
| `EnqueueIdempotencyConflictError` | A retained enqueue key was reused with a different request     |
| `RedriveIdempotencyConflictError` | A redrive request ID was reused with different attribution     |
| `CheckpointConflictError`         | A checkpoint name was reused with a materially different value |
| `CheckpointLeaseLostError`        | A checkpoint save came from a stale generation                 |
| `ProgressLeaseLostError`          | A progress update came from a stale generation                 |
| `ProgressRateLimitError`          | A changed progress update arrived before the 100 ms interval   |
| `WaitConflictError`               | A wait name was reused with a different mode or target         |
| `WaitLeaseLostError`              | A wait was scheduled from a stale generation                   |
| `WaitLimitExceededError`          | A job exceeded 1,000 named waits                               |
| `CancellationRequestedError`      | Abort reason for a requested cancellation                      |
| `DeadlineExceededError`           | Abort reason for an absolute deadline                          |
| `ExecutionTimeoutError`           | Abort reason for a per-attempt execution timeout               |
| `InjectedCrashError`              | A test failpoint fired                                         |

`@workhorse/drizzle` additionally exports `DrizzleQueryError`.

| Command                       | Purpose                               |
| ----------------------------- | ------------------------------------- |
| `workhorse worker --config …` | Run a dedicated worker process        |

## Types

Core exported types include `Queryable`, `Json`, `JobState`, `JobSnapshot`, `ClaimedJob`,
`EnqueueOptions`, `EnqueueRequest`, `EnqueueIdempotency`, `RetryPolicy`, `HandlerContext`, `Handler`,
`WorkerOptions`, `WorkerRuntimeState`, `WorkerMaintenanceTelemetry`, `JobCheckpoint`, `JobWait`,
`JobListQuery`, `JobListPage`, `JobListItem`, `JobTimelineQuery`, `JobTimelinePage`, `DeadLetter`,
`DeadLetterQuery`, `DeadLetterPage`, `RedriveRequest`, `RedriveResult`, `RedriveLineage`,
`CancellationRequest`, `CancelResult`, `QueueHealth`, `RetentionPolicy`, `MaintenancePolicy`, and
`ScheduleDefinition`.

The published `.d.ts` files are the authoritative reference. Source:
[`src/index.ts`](https://github.com/stablemates/workhorse/blob/main/src/index.ts).
