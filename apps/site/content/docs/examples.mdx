Each concept guide owns its example so behavior and code change together. Use this page only to find
the right owner.

## Producing work

- [Quickstart](/docs/quickstart) creates a `Queue`, registers `Worker.handle`, and runs one job.
- [Enqueue and transactions](/docs/enqueue) passes a caller-owned `Queryable` to `Queue.enqueue`.
- [Idempotency](/docs/idempotency) attaches a stable key through `EnqueueOptions.idempotency`.
- [Schedules](/docs/schedules) synchronizes a namespace through `Queue.syncSchedules`.

## Executing work

- [Workers](/docs/workers) registers a handler and defines a dedicated worker process.
- [Durable execution](/docs/durable-execution) uses `HandlerContext.checkpoint` and `sleepUntil`.
- [Progress](/docs/progress) publishes operator state through `HandlerContext.setProgress`.
- [Cancellation](/docs/cancellation) passes `HandlerContext.signal` into interruptible work.

## Operating work

- [Queries and timelines](/docs/queries) reads `JobSnapshot`, `JobListPage`, and lifecycle evidence.
- [Dead letters](/docs/dead-letters) previews failure recovery through `Queue.redriveMany`.
- [Drizzle](/docs/drizzle) binds enqueue to a Drizzle transaction.
- [Hono](/docs/hono) exposes `Queue` through typed middleware.
