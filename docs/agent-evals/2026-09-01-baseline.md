# Agent documentation eval: the 2026-09-01 baseline

The first scored run, and the one every later run is compared against. It measures the published
documentation as it stood on 2026-09-01, before any change in the agent documentation layer.

## Provenance

These four fixtures are **reconstructed, not recorded**. The sessions predate this harness: they
were run by hand for WH-518 and written up as a research note, which stays on the throwaway branch
`research/agent-docs-baseline` at `940eb913` and never merges.

Each fixture transcribes that note's URL trail, install commands, and maintainer's read. Every
scored dimension is derivable from those. Two fields the harness would have captured are absent,
because the note never recorded them: per-fetch content type and byte count. No scored dimension
reads either, which is why the reconstruction is usable rather than merely indicative.

No produced program was kept, so `score` reports the maintainer's read for all three mistakes and
marks every textual signal unclear. A later recorded run keeps its program and gets both.

## What the numbers say

**A against D is the entry point, and nothing else.** The two tasks differ only in start point. D
reached `llms.txt` on fetch 4 and called it its most useful fetch; A spent all fifteen fetches in
HTML and never saw an agent surface at all. The root README carries the pointer and the site's
front door does not.

**Discovery cost, not comprehension, is what separates the sessions.** Every session that reached a
Markdown twin produced transactionally correct code. B and C each spent five to nine fetches on
HTML pages that showed them one language of three before recovering.

**One install command set is broken, and it is the pinned one.** A reconciled two disagreeing pins
into `0.1.0-beta.3` and emitted four commands that fail at the first step. The three sessions that
copied a pin verbatim were fine. That is the evidence behind the decision that no document carries
a version.

**Off-site signature fetches track the missing per-language reference.** D spent its last three
fetches reading TypeScript source on GitHub because `api.md` defers to it; C hand-built a
`pkg.go.dev` URL because no page lists Go signatures; B left for the raw Python README.

## Pass bar for the next run

Set by WH-524 and recorded in ADR 0049. Measured against the same model and prompt as the run being
compared, since a score is evidence about the documentation only in the delta.

- Discovery index non-null for all four tasks, and at most 3.
- Task A within one of task D.
- Zero off-site signature fetches.
- Four of four sessions resolving every install command.
- Zero known mistakes.

Every line is currently missed. That is the point of a baseline.

## Caveat

One model and one prompt, and for this run not even that: the model that produced these sessions
was not recorded, so the fixtures name it `unrecorded`. The absolute numbers mean little. Only the
delta against a run recorded the same way does, and the next run records its own model.
