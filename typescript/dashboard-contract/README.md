# `@stablemates/workhorse-dashboard-contract`

Workhorse is a public beta. It is usable for evaluation and early production adoption, but any
minor release may break compatibility, including the schema. There is no upgrade path between 0.x
releases; ordered migrations begin at 1.0.0.

This type-only package defines the standalone entry point shared by `@stablemates/workhorse` and
`@stablemates/workhorse-dashboard`. Most applications should install `@stablemates/workhorse-dashboard` and use its public
server APIs instead of importing this package directly.
