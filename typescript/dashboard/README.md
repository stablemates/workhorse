# @stablemates/workhorse-dashboard

Workhorse is a public beta. It is usable for evaluation and early production adoption, but any
minor release may break compatibility, including the schema. There is no upgrade path between 0.x
releases; ordered migrations begin at 1.0.0.

Compatibility package for the shared application in `dashboard/app` and the TypeScript backend in
`typescript/dashboard-server`. The facade preserves its public exports and subpaths after the
repository split.
